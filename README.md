## Visão Geral do Projeto

Este repositório contém os resultados de um trabalho avaliativo focado em Modelagem, Arquitetura e Engenharia Reversa. O objetivo principal consistiu em analisar uma plataforma de delivery operante no mercado — a **Tropykaly Pizzas e Lanches** — e, a partir de sua interface e comportamento, deduzir a organização interna do código, seus padrões de projeto e a arquitetura subjacente.

## Organização do Repositório

Os documentos entregues estão divididos da seguinte maneira:

* **analise.md**: Um panorama geral do funcionamento da plataforma e das suposições sobre sua divisão em camadas.
* **comparacao.md**: Um quadro comparativo detalhando as diferenças entre a aplicação real (Tropykaly) e o modelo acadêmico estudado em sala.
* **arquitetura.md**: Uma sugestão de estruturação baseada no padrão MVC, incorporando design patterns para melhorar a escalabilidade.
* **melhorias.md**: Um levantamento de possíveis vulnerabilidades observadas e recomendações técnicas para otimizar a aplicação.
* **modelagem.png**: A representação visual (UML) ilustrando as entidades do sistema, seus atributos e as conexões entre elas.

## Metodologia de Desenvolvimento

Para simular um ambiente de desenvolvimento corporativo, adotei as seguintes práticas e ferramentas:
* **Versionamento (Git/GitHub):** Para registrar todas as alterações do projeto.
* **Uso de Ramificações (Branches):** Para isolar a criação de cada documento e manter a organização.
* **Commits Semânticos (Conventional Commits):** Para garantir um histórico de modificações padronizado e compreensível.
* **Revisão de Código (Pull Requests):** Para emular a etapa de entrega e validação antes de integrar o trabalho final.
