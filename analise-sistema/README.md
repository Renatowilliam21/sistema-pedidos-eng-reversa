# Atividade Avaliativa - Engenharia Reversa, Arquitetura e Modelagem

**Aluno:** William Axel da Silva Ribeiro

**Curso:** Análise e Desenvolvimento de Sistemas (ADS) - IFCE Campus Boa Viagem

**Professor:** Prof. Dr. Renato William Rodrigues de Souza

**Disciplina:** Arquitetura de Sistemas

**Contexto:**
Esta atividade tem como objetivo realizar a análise de engenharia reversa do sistema em produção [Tropykaly Pizzas e Lanches](https://tropykalypizzaselanches.com.br/). A atividade aplica conceitos de Arquitetura de Software, Design, Modelagem UML e Padrões de Projeto, baseando-se exclusivamente no comportamento observado do sistema, uma vez que não há acesso ao código-fonte.

## Estrutura do Projeto

- **README.md**: Identificação do aluno e descrição da atividade
- **analise.md**: Análise do sistema real (Partes 1, 2 e 3)
- **arquitetura.md**: Proposta de arquitetura e padrões de projeto
- **comparacao.md**: Comparação entre o sistema real e o sistema didático
- **melhorias.md**: Problemas identificados e propostas de melhoria

## Objetivo

Aplicar os conceitos estudados em aula para compreender, modelar e propor melhorias em um sistema real, utilizando técnicas de engenharia reversa e análise estrutural de software.
